# Bundle icons

Tauri's bundle step needs icons in five sizes/formats (see `tauri.conf.json > bundle.icon`). Drop the artwork here once it exists; for the demo build, run `cargo tauri icon path/to/source.png` from this directory and Tauri generates all five from a single source PNG (1024×1024 recommended).

`cargo tauri icon` will overwrite anything already in this directory.
